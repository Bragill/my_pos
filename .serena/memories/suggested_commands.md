# Suggested Commands

## General
- `git status`: Check current status of the repository.
- `ls` or `dir`: List files in the current directory.

## Backend (cd POS_Project/backend)
- `npm install`: Install dependencies.
- `npm run dev`: Start development server with nodemon (Port 3001).
- `npm run start`: Start production server.
- `npm run db:migrate`: Run database migrations.
- `npm run db:seed`: Seed database with initial data.
- `node check_db.js`: Utility script to check database integrity.

## Frontend (cd POS_Project/frontend)
- `npm install`: Install dependencies.
- `npm run dev`: Start Vite development server (Port 5174, HTTPS).
- `npm run build`: Build for production.
- `npm run preview`: Preview the production build.
