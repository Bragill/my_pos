# Style and Conventions

## General
- **Naming**: camelCase for variables and functions, PascalCase for React components and classes.
- **UI Framework**: Tailwind CSS for styling.
- **Font**: "Prompt" font for Thai text optimization.

## Frontend (React)
- **Functional Components**: Use functional components with hooks.
- **Context API**: Used for global state management (Auth, Cart).
- **Icons**: Use `@heroicons/react`.
- **Formatting**: Standard JS/JSX formatting.

## Backend (Node/Express)
- **Modular Routes**: API routes are separated into individual files in `src/routes/`.
- **Database Access**: Use the `dbHelper` for all database operations (get, all, run).
- **Environment**: Use `.env` for configuration.

## Thai Optimization
- 100% Thai language support.
- Split layout (70% products, 30% cart).
- Keyboard shortcuts for common POS actions (F2, F9, Esc).
