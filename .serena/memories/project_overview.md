# Project Overview: 🛒 POS ระบบขายหน้าร้าน

A modern Point of Sale (POS) system specifically designed for the Thai market.

## Key Features
- **POS Terminal**: Search/Scan barcodes, cart management, payments (Cash, Card, QR PromptPay).
- **CRM**: Member points, purchase history, discounts.
- **Inventory Management**: Stock in/out, reorder alerts.
- **Reports**: Daily/Monthly sales, best sellers, cashier performance.
- **Shift Management**: Open/Close shifts, cash summary.
- **PWA & Offline**: Installable on home screen, offline functionality via IndexedDB and Service Workers.
- **RBAC**: Admin, Manager, Cashier roles with PIN code login.
- **VAT**: Automatic 7% tax calculation and receipt generation.
